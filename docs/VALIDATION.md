# Validation

Generated by `python -m noisemodel.validation`. Do not edit by hand.

The facade and room part of the model (composite wall with leaks, +3 incidence constant, Sabine absorption) is run on the measured US rooms of `research/R6-validation.md`. Each prediction is the model's outdoor-to-indoor reduction, NLR = free-field level outside minus room level (R6 E2), with the same incident level on every exterior wall of the room. The measurements are FAA loudspeaker tests near the SDF and BWI airports, windows and doors closed; R6 says to compare road-type predictions with them. Where R6 gives no detail the model's defaults fill in (year built unknown: 1980 to 1999 era, 15% window). Room sizes are missing for most cases, so the R3 test bedroom (4 x 3.5 x 2.4 m) stands in.

**No value was tuned.** Nothing marked `sourced` or `calibrated` in `assumptions.yaml` was changed to improve the fit.

The model reads louder indoors than measured (negative error = predicted reduction too small) for the vinyl-sided rooms. In those rooms the vinyl siding wall (OITC 24, NRC lab test, `sourced`) carries most of the transmitted energy, so the result rests on that one rating and on the unknown room sizes; the brick-veneer rooms, where windows and leaks dominate as in the demo unit, are within 2.2 dB. The 1990s leak fraction is `calibrated` (R3 E3) and was not changed. Using the sealed leak fraction for the storm windows (R3 conflict 6) would raise C1 by about 1.3 dB and not close the gap.

Several rooms of one house share identical model inputs (R6 gives no room sizes or window areas), so the model gives them one number while the measurements spread by up to 4.7 dB (C1). That spread is the floor on what this comparison can show without room sizes and window areas.

## Other checks the tests run

- SOUND_MODEL.md section 5 worked example: every step in the V1 review table reproduced to 0.05 dB (bedroom midday 27.15, corridor 19.67, DNL 29.53).
- R3 era table, 65 dBA outside the 4 x 3.5 x 2.4 m bedroom, 15% window: 45.1, 41.5, 41.2, 38.2 dBA.
- All-glass wall: NLR at least 18 dB in every era; 1980 to 1999 gives 45.6 dBA (NLR 19.4) with the V1 leak cap.
- R7 worked example: 66.4 dBA (soft) and 67.6 dBA (hard) with RD-77-108 levels, 65.8 with TNM; Yale St count at 15 m: 63.0 dBA (TNM), 63.3 (RD-77-108).

Known side effect of applying the V1 leak cap as written (`f * min(sum of openings, 0.15 * wall)`): the cap also counts doors. R3's check that a 1.9 m2 exterior door adds 4 to 6 dB to the 15% window room now gives about +2.6 dB instead of +4.3, because the door's leak is cut back to the cap. Both examples have one exterior door, on the living room: a glazed sliding door (zzvymDx5ty7) and a balcony door (Yale St).
